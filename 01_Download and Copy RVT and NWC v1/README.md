# 01. Download and Copy RVT and NWC (v1) — архив

Первая версия пайплайна обмена моделями: выгрузка RVT с RevitServer,
конвертация в NWC, обмен с файловым сервером компании и сервером заказчика.
Внутреннее имя: **DownloadAndCopyRVTNWC**, последняя версия — **1.3 (12.07.2025)**.

> **Проект заморожен как архив и не развивается.** Актуальная версия — в папке
> [02_Download and Copy RVT and NWC v2](../02_Download%20and%20Copy%20RVT%20and%20NWC%20v2/README.md):
> там исправлены критичные проблемы этой версии, добавлено подключение VPN
> и переработан редактор настроек. Правки, если понадобятся, вносятся только в v2.

## Зачем хранится

- Это то, что сейчас работает в регламенте (Планировщик заданий) — до перевода
  площадки на v2.
- По этой версии видно, какие проблемы исправила вторая, — см. её
  [CHANGELOG](../02_Download%20and%20Copy%20RVT%20and%20NWC%20v2/CHANGELOG.md).

## Состав

- `src/00_Start_RunScript.ps1` — оркестратор: читает `config.json`, запускает шаги.
- `src/01…07_Step*.ps1` — шаги пайплайна (скачивание, конвертация, обмен).
- `src/log.ps1` — логирование.
- `src/Settings.html` — офлайн-редактор `config.json`.
- `CHANGELOG.md` — история версии.

Рабочий `config.json` с адресами серверов в репозиторий не попадает
(см. корневой `.gitignore`); заполняется через `Settings.html` по месту.

## Запуск (как было в эксплуатации)

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File "src/00_Start_RunScript.ps1"
```

Сборки у проекта нет — скрипты копируются на рабочую станцию как есть.

⚠️ Исторические скрипты v1 сохранены в кодировке **CP1251** (не UTF-8 с BOM,
как принято в остальном репозитории). Перед правкой любого файла проверяйте
фактическую кодировку — но помните, что правки в v1 не ведутся.
