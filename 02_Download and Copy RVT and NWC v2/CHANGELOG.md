# CHANGELOG — Download and Copy RVT and NWC (v2)

## 2.3 — 13.08.2026

- Исправлена кодировка вывода утилит Autodesk: `RevitServerTool` и
  `FiletoolsTaskRunner` пишут в OEM-кодировке консоли, лог теперь читает
  её корректно — кириллица в путях не искажается.
- `Settings.html`: у полей путей к утилитам — выпадающий список версий
  (2020–2026) и кнопка «Стандартный путь».
- Автокоррекция слешей в путях при сборке `config.json`
  (UNC-префикс `\\server\share` сохраняется).
- В поставку идёт обезличенный шаблон `config.template.json`; при сборке
  сверяются ключи шаблона и рабочего конфига.
- `build.ps1`: корректная обработка регулярных выражений JS при удалении
  комментариев, проверка синтаксиса собранных файлов.

## 2.2 — 12.08.2026

- `Settings.html` переработан: схема маршрута файлов вместо списка галочек,
  проверка настроек по ходу правок, фильтры-теги вместо строк через запятую,
  сохранение файла на месте (File System Access API), полная работа офлайн
  без внешних ресурсов.
- Инструкция пользователя переведена в Markdown (`docs/Инструкция.md`);
  PDF собирается при сборке поставки.
- Добавлен `build.ps1` — сборка поставки в `dist/`: удаление комментариев,
  лицензионный заголовок, пересборка PDF.

## 2.1 — 12.08.2026

- Подключение VPN перед запуском: SoftEther (`vpncmd.exe`) или встроенный
  VPN Windows (`rasdial.exe`). Блок `Vpn` в `config.json`, по умолчанию
  выключен.
- Соединение, поднятое вручную до запуска, не разрывается. Если VPN
  не поднялся — шаги не выполняются, пайплайн возвращает код 1.
- Факт подключения проверяется доступностью узла (`TestHost`/`TestPort`),
  а не только статусом клиента.
- Пароли в конфигурации не хранятся; при необходимости указывается имя
  переменной окружения.
- Сохранение настроек больше не удаляет незнакомые странице ключи конфига.

## 2.0 — 12.08.2026

Исправлены критичные проблемы первой версии:

- Все скрипты переведены в UTF-8 с BOM — корректное чтение и Windows
  PowerShell 5.1, и PowerShell 7.
- Устранено зависание на выводе внешних утилит больше 4 КБ; добавлены
  таймауты с завершением дерева процессов.
- Шаги возвращают статус оркестратору; пайплайн возвращает Планировщику
  код 0/1 (раньше итог всегда был «завершено»).
- Пустой фильтр больше не превращается в «копировать всё» или
  «не выгружать ничего».
- Папка логов создаётся рядом со скриптом независимо от рабочего каталога.
- Служебные NWD удаляются адресно, а не по маске `*.nwd`.
- Успех внешних процессов определяется по коду возврата, а не по поиску
  слова «ERROR» в выводе.
- Общая логика вынесена в `common.ps1`.
