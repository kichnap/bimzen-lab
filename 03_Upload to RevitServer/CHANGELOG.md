# CHANGELOG — RvsUpload

## 0.15.3 — 22.08.2026

- Примеры `.cmd` в поставке не запускались: файлы записывались в UTF-8
  с меткой порядка байтов, и интерпретатор командной строки принимал
  метку за часть первой команды. Теперь примеры пишутся в кодировке
  консоли (CP866) без метки.
- Примеры `.cmd` записываются с переводами строк Windows (CRLF). С переводами
  строк Unix интерпретатор перескакивал середину строки на границе
  внутреннего буфера, и вместо запуска утилиты появлялось
  `'ce' is not recognized`.
- Из примеров `.cmd` убрана команда `chcp 65001`: на строках с кириллицей
  она добавляла к этому свои искажения.
- Пути в примерах `.cmd` записаны латиницей: строка команды читается
  в кодировке консоли, и кириллица в ней зависит от настроек окна.
  Пояснения на русском в комментариях остались.
- В примерах `.ps1` первыми строками указана команда запуска с кавычками:
  без них `powershell -File` обрывает путь на первом пробеле и отвечает,
  что файл имеет расширение, отличное от PS1.
- Файл со списком моделей переименован в `models.example.txt`.
- В поставке появился `Установить.cmd`: установка двойным щелчком с окном,
  которое не закрывается само. Прежний способ — правой кнопкой по
  `Установить.ps1` — закрывал окно сразу после последней строки, и ни
  результат, ни текст ошибки прочитать было нельзя.
- `Установить.ps1`, запущенный из проводника, теперь ждёт нажатия Enter
  перед закрытием окна, в том числе при ошибке. Ключ `-БезПаузы` отключает
  ожидание для вызова из других скриптов.

## 0.15.2 — 17.08.2026

- Раскладки `--structure disk` и `--structure server` проверены на живом
  сервере.
- Чтение дерева сервера по REST повторяется до трёх раз при обрыве
  соединения; ответы сервера с кодом ошибки не повторяются.

## 0.15.1 — 17.08.2026

- Предполётная проверка тестирует канал передачи моделей net.tcp
  (порт 808), а не только административный REST: разыгрывается начало
  сеанса .NET Message Framing, по ответу видно, работает ли служба.
  Три попытки на случай самопроизвольного обрыва соединения.
- Тестов: 178.

## 0.15.0 — 16.08.2026

- `--source-folder` — источником моделей может быть папка (с подпапками;
  `--no-recurse` — только верхний уровень). Резервные копии Revit
  (`Модель.0001.rvt`) и служебные папки (`*_backup`, `Revit_temp`)
  пропускаются, каждый пропуск отмечается в логе.
- `--structure flat|disk|server` — три раскладки моделей на сервере:
  всё в одну папку, повторение структуры диска, возврат моделей туда,
  где они уже лежат на сервере. Модель, которой нет на сервере или которая
  нашлась в нескольких папках, отбраковывается поимённо — пакет
  не отменяется.
- Примеры в поставке — в двух видах: `.cmd` (двойной щелчок)
  и `.ps1` (Планировщик заданий).
- Тестов: 164.

## 0.14.0 — 16.08.2026

- Проверено живыми прогонами на Revit 2021–2025 (полный круг: заливка,
  проверка через REST, отказ повторной заливки без `--overwrite`, обратное
  скачивание). Для 2026 — предполёт и `--dry-run`.
- `build.ps1 -Package` — готовая поставка для передачи: установщик
  `Установить.ps1`, инструкция в HTML, страница настроек, примеры команд,
  `bin`. Надстройки разложены по средам выполнения: `net48`
  (Revit 2021–2024) и `net8` (2025 и новее).
- Страница настроек переработана: блок «Путь модели» с рубежами проверок,
  готовая команда запуска для копирования, расширенная проверка значений
  (лимиты пути по версии сервера, сроки ожидания).

## 0.13.x — 14–15.08.2026

- `--idle-timeout` (по умолчанию 20 мин) — сторож зависания посреди пакета
  по молчанию лога аддина; в отчёте — шаг, на котором всё остановилось.
- Создание папок с кириллическими именами на Revit Server 2021 работает:
  проверяется факт создания, а не код ответа сервера.
- Гибель Revit посреди пакета: повтор заливает только оставшиеся модели,
  залитые не перезаливаются.
- `smoke-test.ps1` актуализирован под текущую схему работы; полный прогон
  уровня 4 пройден.
- Обрыв заливки не портит существующую модель на сервере: Revit Server
  не подменяет её, пока заливка не завершена.
- Примечание: в поставке Revit 2025 отсутствует `RevitServerTool.exe` —
  скачивание с Revit Server этой утилитой на 2025+ невозможно.

## 0.12.0 — 14.08.2026

- `--config settings.json` — настройки в файле; аргументы командной строки
  перекрывают файл, отсутствующий ключ берёт умолчание утилиты.
- `Settings.html` — автономная страница-редактор настроек (один файл,
  работает без интернета); образец — `settings.template.json`.
- Тестов: 132.

## 0.11.0 — 14.08.2026

- Проверка свободной лицензии до запуска Revit — при сетевом
  лицензировании (`lmutil lmstat`); при single-user занятость заранее
  узнать нечем, утилита сообщает об этом в лог.
- `--startup-timeout` (по умолчанию 5 мин) — сторож застревания Revit
  до загрузки аддина (модальные окна лицензии, восстановления, доверия).
  Застревание на старте отменяет повторы.

## 0.10.0 — 14.08.2026

- `--retries <n>` — повтор незалитых моделей перезапуском Revit
  (максимум 10). У каждой попытки своя рабочая подпапка с логами;
  устойчивые отказы отбраковываются до запуска Revit и в цикл не попадают.
- В логе различаются отмена человеком и внутреннее падение Revit.

## 0.9.x — 14.08.2026

- Модели младших версий заливаются, Revit обновляет их автоматически
  (это дольше и отмечается в логе). Отклоняется только модель новее Revit.
- Отбраковка позадачная: непригодная модель помечается проваленной,
  остальные заливаются; `result.json` описывает весь запуск.
- Revit гарантированно закрывается: штатный `ExitRevit` плюс сторож
  с принудительным завершением всего дерева процессов.
- Диалоги Revit подавляются по явной таблице ответов; неизвестный диалог
  отмечается в логе отдельно.
- `--dest-name` и вторая колонка списка — явное имя модели на сервере.

## 0.8.x — 14.08.2026

- Модель без рабочих наборов заливается: worksharing включается
  автоматически (`EnableWorksharing`).
- Имя модели на сервере всегда совпадает с заданным — никаких суффиксов
  и молчаливых переименований.
- `--close-worksets` проверен: содержимое модели не теряется, закрытые
  наборы остаются в файле целиком.

## 0.2.0–0.7.0 — 14.08.2026

- Становление утилиты: от первой собирающейся версии до первой полностью
  автоматической заливки на живой Revit Server.
- Итоговая схема работы: CLI → предполёт через Admin REST API → запуск
  Revit без аргументов → аддин `IExternalApplication` получает задание
  через переменную окружения → `SaveAs(SaveAsCentral)` → `result.json`.
  Journal-файл не используется.
- Лимиты сервера (длина пути папки и имени модели) читаются с самого
  сервера и проверяются до запуска Revit.
- Убрана зависимость от Newtonsoft.Json: JSON через BCL, внешних пакетов
  у поставки нет.
