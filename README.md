# bimzen-lab — мини-утилиты для BIM-специалистов

Набор небольших полезных утилит, скриптов и пайплайнов для BIM-специалистов:
автоматизация Revit Server, конвертация моделей, обмен с заказчиками.
Репозиторий пополняется.

Разработчик — **ПАНЧИК.РФ** · [bimzen.ru](https://bimzen.ru)

## Соглашения

- Каждый проект — отдельная папка `NN_Название`. **Внутренняя структура зависит
  от типа проекта** — единого шаблона нет, смотрите `README.md` конкретной папки.
- **Папок `version X` больше нет.** Историю версий держит git: старые состояния
  доступны в истории и тегах, а не копиями каталогов. Первая версия пайплайна
  выделена в отдельный проект `01_… v1` и заморожена как архив.
- Документация — в `.md` файлах рядом с кодом (`README.md`, `CHANGELOG.md`).

## Сборка под свою организацию

Поставки брендируются при сборке: в исходниках вместо готовых названий стоят
подстановки `{{ORG}}`, `{{UNIT}}`, `{{DEV}}`, `{{YEAR}}`, которые `build.ps1`
проекта заменяет значениями из [branding.psd1](branding.psd1) одним проходом
по готовой поставке:

```powershell
.\build.ps1 -Package                                  # сборка с умолчаниями
.\build.ps1 -Package -Organization "ООО «Ромашка»"    # поставка для вашей организации
```

Ключ `-Organization` меняет только название организации-получателя в
инструкциях и на страницах настроек. Разработчик (`{{DEV}}`) настройкой
сборки не является и не меняется. Механика — [tools/Branding.ps1](tools/Branding.ps1),
самопроверка — [tools/Branding.Tests.ps1](tools/Branding.Tests.ps1).
